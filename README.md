# job portal frontend

#### React, TypeScript, Mantine, Tailwind CSS

### features

#### Auth JWT

- login register => applicant & employer
- create profile => applicant & employer

#### Applicant

- all jobs list view
- job details
- apply to job after creating profile
- applied jobs section
- save job and its section

#### Employer

- create/update job
- all created jobs list view
- find talent for the created job
- view applicant details
- accept/reject applicant
